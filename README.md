# 💻 Repositório Geral — Estudos e Projetos

Bem-vindo(a) ao meu repositório geral de desenvolvimento! 👋

Este repositório reúne atividades, exercícios, projetos e estudos desenvolvidos ao longo da minha jornada na área de tecnologia.

Aqui estão organizados projetos utilizando diferentes linguagens e tecnologias, com foco no desenvolvimento de lógica de programação, desenvolvimento web, aplicações desktop e automação.

---

## 🚀 Tecnologias e Linguagens

As principais tecnologias presentes neste repositório são:

| Tecnologia | Aplicações |
|---|---|
| ☕ Java | Lógica de programação, aplicações e interfaces gráficas |
| 🐍 Python | Exercícios, automações e desenvolvimento de scripts |
| 🌐 HTML | Estruturação de páginas web |
| 🎨 CSS | Estilização e desenvolvimento de interfaces |
| ⚡ JavaScript | Interatividade e desenvolvimento web |
